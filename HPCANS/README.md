# HPCANS: quiz answer helper for the TI-84 Plus CE

## 1. Put it on the calculator

1. Install **TI Connect CE** on the computer and plug in the calculator.
2. Open the folder **`TRANSFER`**. Select **all** the `.8xp` files in it (the program needs every one).
3. Drag them onto the calculator in TI Connect CE ("Calculator Explorer"). When it asks where to
   put them, choose **RAM** (not Archive).

Do not paste the `.txt` files into the Program Editor; that gives "Bad token!". Always send the `.8xp` files.

## 2. Start it

Press `prgm`, choose **HPCANS**, and press `ENTER` twice. Run only HPCANS; the other programs are
its helpers. If the calculator says it is out of memory, archive or delete other programs first. HPCANS needs about
NNN KB of RAM.

## 3. Pick what the problem LOOKS like

```
1:F+G  OR  F/G         two functions added, multiplied, divided; domains
2:F(G(X))              composition, f(g(5)) from graphs
3:F⁻¹(X)  INVERSE      find / verify an inverse, HLT
4:A*F(BX+C)+K          transformations
5:ABS BARS             |f(x)|  or  f(|x|)
6:KX^P  OR  ROOTS      power functions
7:DECOMPOSE H(X)       write h as f(g(x))
```

Then press the number for **WHAT DO THEY WANT?**, type the numbers you see on the paper, and copy the
line(s) under **ANSWER:**.

* Press a number key to choose; no `ENTER` is needed on menus.
* `CLEAR` goes back.
* `ENTER` on an empty number means "no number there". It counts as 1 in front of F or X, and 0 for a missing
  `+ number`.
* At `ENTER=MORE`, press `ENTER` to see the rest of the answer.

## 4. Typing numbers

* **Negative numbers:** use the gray **`(-)`** key (left of `ENTER`), not the `-` minus key. A lone
  `(-)` means -1.
* **Fractions:** type `2/3` with the `÷` key. Answers are always exact, like `-17/4`, never `-4.25`.
* **Infinity** (for domains and ranges): type the letter `I`: press `ALPHA` then `x²`. A lone `I` is infinity; `(-)I` is negative infinity.
* **X** (in DECOMPOSE): the `X,T,θ,n` key.
