# PHYSICS: AP Physics 1 Unit 1 (Kinematics) for the TI-84 Plus CE

One program, **`PHYSICS.8xp`** (61.9 KB). It contains both parts you asked for:

* **Solvers** (A–K): VOVFSTA, free fall, horizontal launch, angled launch, the throw lab worked
  backward, river crossing, chase problems, vector components, average speed/velocity, factor of
  change, and lab tools. Every solver shows each step on its own screen (which equation and why,
  the numbers substituted, intermediate values), then a summary.
* **Formula reference**: scalars vs vectors, the 5 equations (each with its missing variable),
  free fall, graph stacks, factor-of-change rules, chase problems, horizontal and angled launch,
  river crossing, and the labs.

Class conventions throughout: g = 9.8 m/s², up is positive (free fall a = −9.8 m/s², even at the
top), no air resistance, displacement is S, variables V0 VF S T A, angles in degrees, answers to
3 significant figures with units and signs (`VF = -29.7 M/S (DOWN)`).

## 1. Send it to the calculator (TI Connect CE + USB cable)

1. Install **TI Connect CE** (free, education.ti.com) on a Windows or Mac computer and open it.
2. Turn the calculator on and connect it with its USB cable.
3. Click **Calculator Explorer** (left sidebar). Your TI-84 Plus CE appears in the list.
4. Drag `PHYSICS.8xp` onto the calculator (or **Actions → Send to Calculators** and pick the file).
5. If the send dialog lets you choose a location, choose **RAM**. Click **Send**. If it says the
   program already exists, choose **Replace**.
6. Check: press `[prgm]` on the calculator. **PHYSICS** is in the list.

If you sent the earlier 11-file version (PHYSOLVE, PHYSREF and nine Z… programs), delete those to
free memory: `[2nd][+]` (MEM) → **2:Mem Management/Delete** → **7:Prgm**, move to each one,
press `[del]` and confirm.

## 2. Run it (PRGM key)

1. Press `[prgm]`, move to **PHYSICS**, press `[enter]` (the home screen shows `prgmPHYSICS`),
   press `[enter]` again.
2. Main menu: **1 SOLVERS**, **2 FORMULA REFERENCE**, **3 QUIT**. Pick with the number key
   or the arrows and `[enter]`.
3. Solvers are on two pages (option 6 **MORE >** goes to page 2; page 2's last option **BACK**
   returns). The last option of page 1 is **QUIT TO MAIN MENU**.
4. At every paused screen press `[enter]` to continue.
5. Typing values: numbers then `[enter]`. **Negative numbers need the `(−)` key**, not the minus
   key. In the VOVFSTA solver type **999** for each of the two unknowns.
6. Always leave with QUIT (main menu option 3). That restores your variables (see "What it changes").

Quick check after sending: PHYSICS → 1 SOLVERS → 1 VOVFSTA SOLVER, `[enter]` past the info screen,
then 8, 999, 120, 999, 1.5. The summary shows `VF = 20.6 M/S` and `T = 8.39 S`.

## 3. If you see an error

* **ERR:ARCHIVED**: the program is in archive memory. `[2nd][+]` (MEM) → **2:Mem Management/Delete**
  → **7:Prgm** → move to PHYSICS (it has a `*`) → `[enter]` removes the `*` (moves it to RAM) →
  `[2nd][mode]` (QUIT). PHYSICS calls itself for its shared routines, so keep it in RAM.
* **ERR:MEMORY**: not enough free RAM (PHYSICS needs about 62 KB). In the same Mem Management
  screen, archive things you don't need tonight (move to them, `[enter]` adds a `*`; archiving keeps
  them) or delete the old 11-file version. Then run PHYSICS again.
* **ERR:SYNTAX right after typing a number**: you used the minus key `[−]` for a negative number.
  Use `(−)`.
* On any error screen choose **1:Quit**. (2:Goto opens the program editor.) After an error, your
  variables are not restored; run PHYSICS and QUIT normally to clean up its temporary list.
* If your teacher uses Press-to-Test mode, programs are disabled until it is turned off.

## 5. What it changes on your calculator

* Sets **Degree** mode (and leaves it in Degree).
* Uses the real variables A–W and Z as scratch, but **saves them when it starts and restores them
  when you QUIT**, using a temporary list `ʟPSAV` that it deletes at QUIT. It never touches R, T, X,
  Y or θ (graphing and the solver use those), never touches L₁–L₆ or any other list, and never
  touches your other programs.
* Uses the string variables Str0–Str4, Str8 and Str9 as scratch.

## 7. How it was built and verified

* **Source → .8xp**: `python3 tools/build.py` tokenizes every module in `src/` with
  [tivars_lib_py](https://github.com/TI-Toolkit/tivars_lib_py) (TI-Toolkit, by adriweb et al.), merges
  them into `PHYSICS.txt` with `tools/merge.py`, and builds `PHYSICS.8xp`. It then re-opens each file,
  detokenizes it with tivars and diffs it against the source: every diff is empty
  (`build/ROUNDTRIP.md`). The build also lints the token stream: only commands that exist on the CE,
  no lowercase-letter tokens in code, 26-character lines, ≤ 7 menu options, no colons or empty
  strings, no labels that collide with calculator tokens. tivars' default "smart" mode would have
  mis-tokenized `"…"→Str9` in 8 of the modules (as letters S,t,r,9), so the build tokenizes code and
  strings separately.
* **TI-Basic trace**: `tools/tisim.py` is an interpreter for the TI-Basic used here. It executes the
  `.8xp` token stream with the CE's 26×10 screen, 14-digit decimal arithmetic, the calculator's
  errors (DIVIDE BY 0, NONREAL ANS, DOMAIN, …), and memory-leak detection (a jump out of an open
  If/While/For block).
* **Python reference**: `reference/*.py` mirror each solver line for line.
* **Tests** (`tests/`): 192 module tests (every menu path, impossible inputs, edge cases, random
  physics fuzzing), all passing against both the separate modules and the merged `PHYSICS.8xp`;
  your 12 required cases (30 values) all match (`build/TEST_REPORT.md`); and 16,000 random walks
  through the menus with adversarial inputs (including a worst-case-width mode where every number is
  9 characters wide) with no errors, leaks, scrolling or cut-off lines.
* **Not tested on a physical calculator.** Everything above ran in the simulator, so do the quick
  check in section 2 after sending.

Rebuild and re-test:

```
pip install tivars            # or: pip install git+https://github.com/TI-Toolkit/tivars_lib_py
python3 tools/build.py        # build + lint + round-trip
for t in tests/test_*.py; do python3 $t; done                      # modules
for t in tests/test_*.py; do TISIM_SINGLE=1 TISIM_FROM=8xp python3 $t; done   # merged PHYSICS.8xp
python3 tests/test_user_cases.py                                   # the 12 required cases
python3 tests/fuzz_menus.py 5000                                   # random menu walks
```
