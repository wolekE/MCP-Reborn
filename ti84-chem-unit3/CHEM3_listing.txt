CHEM3 for the TI-84 Plus (honors chem Unit III answer key + step-by-step work)
==============================================================================

EASIEST WAY: send CHEM3.8xp with TI Connect CE (free from education.ti.com).
  Plug in the calculator, drag CHEM3.8xp onto it, and pick RAM (not Archive).
  If it asks to replace the old CHEM3, say yes.  It needs about 10 KB of free RAM.

RUN IT: PRGM, pick CHEM3, ENTER, ENTER.
  Pick a menu option with its number.  ENTER = next screen.
  Each section goes back to the menu when it ends.  7:QUIT exits.
  Press ON to stop it any time (then 1:Quit).

TYPING IT IN BY HAND (only if you have no cable -- it is 300 lines)
  PRGM > NEW > 1:Create New, type CHEM3 (ALPHA is already on), ENTER.
  Every line below starts with ":" -- the calculator adds that, don't type it.
  Press ENTER at the end of each line.
  Commands (press PRGM while editing):
    ClrHome   PRGM > I/O > 8
    Disp      PRGM > I/O > 3
    Pause     PRGM > CTL > 8
    Lbl       PRGM > CTL > 9
    Goto      PRGM > CTL > 0
    Menu(     PRGM > CTL > C:Menu(   (shortcut: PRGM, then ALPHA, then PRGM)
  Characters:
    "        ALPHA then +
    space    ALPHA then 0
    =        2ND then MATH (TEST menu) > 1
    letters  ALPHA then the key (2ND ALPHA locks ALPHA on for whole words)
    , ( ) . + - * /   their own keys (- is the minus key, * is the x key)
  Type every character exactly as shown.
